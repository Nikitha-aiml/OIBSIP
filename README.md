# EDA on Retail Sales Data

## Objective

Perform Exploratory Data Analysis (EDA) on retail sales data to uncover customer behaviour patterns, sales trends, and business insights.

## Dataset

Retail Sales Dataset

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data Inspection
- Missing Value Analysis
- Descriptive Statistics
- Monthly Sales Trend
- Quarterly Sales Trend
- Customer Age Analysis
- Gender Distribution
- Product Category Analysis
- Revenue Analysis
- Correlation Heatmap
- Revenue by Age Group

## Key Insights

- Identified top-performing product categories.
- Analyzed seasonal sales patterns.
- Studied customer demographics.
- Generated business recommendations based on findings.
