# 📊 Exploratory Data Analysis (EDA) on Retail Sales Data

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a retail sales dataset to uncover valuable business insights, customer purchasing patterns, and sales trends using Python.

The analysis involves data cleaning, statistical summaries, visualizations, and interpretation of results to support data-driven business decisions.

---

## 🎯 Objective

- Understand the structure of the retail sales dataset.
- Clean and preprocess the data.
- Perform descriptive statistical analysis.
- Visualize important sales patterns.
- Generate meaningful business insights.

---

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Dataset

**Dataset:** `retail_sales_dataset.csv`

The dataset contains retail transaction information such as:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## 📊 Exploratory Data Analysis

The following analyses were performed:

- Dataset inspection
- Handling missing values
- Checking duplicate records
- Descriptive statistics
- Distribution of numerical features
- Product category analysis
- Gender-wise purchasing analysis
- Age distribution analysis
- Correlation heatmap
- Sales trend visualization

---

## 📈 Key Insights

- The dataset contains clean and well-structured retail transaction records.
- Total sales vary across different product categories.
- Customer age influences purchasing behaviour.
- Male and female customers exhibit different buying patterns.
- Certain product categories contribute significantly to overall revenue.
- Correlation analysis highlights relationships between quantity purchased and total sales.

---

## 📌 Conclusion

Exploratory Data Analysis helped identify customer behaviour, purchasing trends, and important sales patterns within the retail dataset. These insights can assist businesses in making informed decisions regarding inventory management, targeted marketing strategies, and improving customer satisfaction.
